# Counter-Strike 2 Assets for Minecraft

This is a client-side Minecraft Fabric mod for version 26.3, based on my original 1.16 mod that brought Counter-Strike assets into Minecraft.

Due to version incompatibilities and the release of Counter-Strike 2, the original 1.16 mod had to be migrated. This migration was done by Claude Opus 5.5, so expect bugs and weird behavior!

I also switched to newer CS2 models instead of the original CS:GO assets.

Due to time constraints, I only included the **AWP Asiimov** and the **M9 Bayonet** in the released JAR.

## Building the Mod

If you want to build this mod yourself, make sure to import the Counter-Strike 2 assets from your own game installation.

If you're not sure how to do that... just give up!
